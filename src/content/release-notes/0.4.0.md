## Quacky

The app has a new name. Everything it did before, it still does — the rename
touches the product name, the bundle identifier and the window title, nothing
about how transcription works.

Because the bundle identifier changed, macOS treats this as a new application.
Microphone and Accessibility permissions have to be granted once more, and the
app starts with a fresh data directory, so models are downloaded again.

### Double tap to keep recording

Push-to-talk records while you hold the key. Now a **double tap** latches the
recording instead: it keeps running hands-free until you tap the key again,
which is what you want for anything longer than a sentence.

- **Hold** — records while held, exactly as before.
- **Double tap** — a second start sound confirms the latch, and a small lock
  appears on the recording bar. Recording continues with the key released.
- **Tap once** to finish and transcribe, or **Escape** to discard.

Holding still behaves the way it always did, so nothing has to be relearned.
The feature can be switched off under _General → Double Tap to Keep Recording_,
and the window a second tap has to land in is adjustable in _Debug_.

One trade-off worth knowing: a single tap now waits out that window (350 ms by
default) before it starts transcribing, because until the window closes the tap
might still turn out to be the first half of a double tap.

On Linux the setting starts switched off. X11 fakes a key release before every
repeated key press, which at some repeat settings is indistinguishable from a
deliberate double tap.

### Emil Mode is gone

The rainbow accent cycling has been removed along with its setting. Accent
colours are unaffected — pick one under _General → Accent Colour_ as before.
